# Data sources

Review data: Hisham Abdelqader (2025), *Steam Games Metadata and Player Reviews (2020–2024)*, Mendeley Data, version 2. [DOI: 10.17632/jxy85cr3th.2](https://doi.org/10.17632/jxy85cr3th.2). License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Project transformations include source selection, language and date screening, exact-text deduplication, retrieval, and derived analysis. The included subset contains reference codes and rankings; it does not redistribute the full review archive.

Official fix statements and their source URLs are recorded in [queries.json](evaluations/2026-11-03/inputs/queries.json). Announcement dates and archived review dates do not establish review-edit history, a player's installed build or repair causality.

The dataset's license applies to that dataset. No blanket software or third-party content license is granted by this repository.
